## Descrição
Este repositório contém os dashboards autorais criados no Power BI, bem como os dados originais e tratados utilizados, e uma breve apresentação dos Indicadores-Chave de Desempenho (KPIs) e análises estatísticas aplicadas e interpretação das informações obtidas.
